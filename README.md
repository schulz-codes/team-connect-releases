# TeamConnect – Downloads

Release zips of TeamConnect, the team presence menu bar app of schulz.codes.
The source code is private; this repository only hosts the downloads for Homebrew.

```sh
brew install --cask schulz-codes/tap/team-connect   # install
brew upgrade --cask team-connect                    # update
```

First launch: System Settings → Privacy & Security → **Open Anyway** (the app is not notarized).
Sign in with your @schulz.codes Google account. Without such an account the app can't be used.
